FIB — сайт с базой данных SQLite

ЗАПУСК НА WINDOWS
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Выполните:
   py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python app.py
4. Откройте http://127.0.0.1:5000

АККАУНТ СОЗДАТЕЛЯ
Первый аккаунт создаётся автоматически при запуске сайта:
Логин: X1nce
Пароль: cb&VLVJ6$RuSyOHdsNynUuZ4]-+vV:[D
Создатель может создавать аккаунты всех должностей, кроме второго Создателя.
Директор может создавать только Заместителя директора, Главу отдела и Заместителя главы отдела.
Для каждого сотрудника указываются имя, фамилия, логин и пароль.

СТАТУСЫ ЗАЯВЛЕНИЙ
- Новая
- На обработке
- Принято
- Отклонено (с обязательной причиной)

Номер паспорта: целое число от 1 до 100 000 000. При отклонении заявления обязательно указывается причина. Список сотрудников онлайн обновляется автоматически, пока они авторизованы и открыта панель сотрудников.

Данные хранятся в instance/fib.db. Не удаляйте этот файл, иначе потеряете базу.
Для публикации в интернете используйте хостинг с постоянным диском (persistent disk/volume),
иначе SQLite-база может сбрасываться при пересоздании контейнера.
Для production задайте постоянный SECRET_KEY в переменных окружения и используйте HTTPS.
Запуск на сервере через Procfile: gunicorn app:app

Важно: сайт и база работают на сервере. Один только HTML-файл не может безопасно
хранить общие заявления и аккаунты между разными посетителями.
